# 사교원 품에 코퍼스

여기에 올린 마크다운(`.md`)을 **품에 AI가 읽습니다.** 사교원 사이트에서 AI에게 물었을 때
나오는 답이 여기 있는 자료를 근거로 바뀝니다.

## 쓰는 법

1. `.md` 파일을 이 저장소에 올린다 (폴더로 나눠도 됩니다)
2. 끝. **5분 안에** 품에가 읽습니다

승인 절차가 없습니다. 품앗이(지미)를 거치지 않습니다. 누가 검토하고 통과시켜 주는 단계가
없습니다 — 올리면 들어갑니다.

## 무엇이 들어갔는지

`_기록/반영기록.tsv` 에 자동으로 쌓입니다. 언제·어떤 커밋·어떤 파일·몇 바이트·반영 뒤
검색 조각이 몇 개가 됐는지. 이건 **검사 기록이 아니라 이력**입니다. 막는 데 쓰지 않습니다.

## 넣지 말아야 할 것

🔴 **개인정보.** 조합원 명부, 주민등록번호, 개인 연락처, 계좌번호.
AI는 읽은 것을 답변에 그대로 내놓습니다. 명부를 다뤄야 하면 햇소자 자료함을 쓰십시오 —
그쪽은 브라우저 안에서만 처리하고 서버로 보내지 않습니다.

주민등록번호 형태가 보이면 반영기록에 표시가 남습니다. **막지는 않습니다.** 넣을지 말지는
사교원이 정합니다.

## 잘 읽히는 형태

- 파일 하나에 주제 하나
- `##` 제목으로 단락을 나눈다 — 이 단위로 검색됩니다
- 파일 이름에 핵심어를 넣는다 (`완도군_영농형태양광_공문_2026.md`)
- 표·목록 그대로 괜찮습니다. 원문을 다듬지 않아도 됩니다

## 무엇을 넣으면 좋은가

완도군 공문과 회신, 용역·사업 자료, 사업계획서·정관·의사록, 교육 자료,
그동안 작성해 둔 서류. **사교원만 가진 것이 가장 값집니다** — 인터넷에 있는 일반 자료는
AI가 이미 압니다.

## 안 되는 것 같을 때

`_기록/반영기록.tsv` 에 그 커밋이 적혔는지 먼저 보십시오.
- 적혀 있는데 답이 그대로다 → 질문이 그 자료와 안 맞거나, 자료 안 표현이 질문과 다릅니다
- 안 적혀 있다 → 배관 문제입니다. 데카가 지미에게 알리면 됩니다
